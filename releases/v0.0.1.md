Initial public release of Cash Counter, with the Till desktop workspace.

- Named CAD registers, opening counts, cash-in/cash-out entries and closing reconciliation.
- SQLite persistence, transactional writes, paginated history and duplicate-submit protection.
- Native GPUI interface with keyboard controls and an embedded Windows icon.
- Per-user Windows x64 installer with shortcuts, bundled runtime and uninstall support.
- MIT-licensed source, dependency notices and SHA-256 release checksums.

Download `Till-0.0.1-windows-x64-setup.exe` and compare its hash against
`SHA256SUMS.txt`. Windows 10 version 1703 or later and Windows 11 x64 are supported.
The installer is unsigned. Uninstall preserves the database.

Known limitation: an upstream accessibility integration issue can cause a panic
on native Windows shutdown with active accessibility clients. Multi-currency
setup, denomination counting and cloud synchronization are not included.
