Cash Ledger 0.0.3 fixes first-run company onboarding on shorter windows.

- Keeps the setup form at its natural height and adds a vertical scrollbar so all fields and the Continue button remain reachable.
- Runs checks, Windows installer packaging, version tagging, and release publication sequentially in one CI run on main. Pull requests run checks and packaging without publishing.

Download `CashLedger-0.0.3-windows-x64-setup.exe` and verify it against
`SHA256SUMS.txt`. Existing application updates discover this release after
publication. Company settings, credentials, and cash records are preserved.

The installer remains unsigned. Windows is the supported distribution target;
the existing limitations described in the documentation still apply.
