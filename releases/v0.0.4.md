Cash Ledger 0.0.4 updates native components and fixes sign-in and installer handoff.

- Enter signs in from either login field.
- Windows update installation uses compatible DOS/UNC paths and records a setup log for failed attempts.
- Navigation uses tabs; settings use accordion sections and an A4/Letter selector.
- Reports include a searchable register selector, date shortcuts, status tags, and structured cash totals.
- Forms, feedback, action icons, password reveal controls, and the automatic-update switch use the compatible GPUI component library.

Download `CashLedger-0.0.4-windows-x64-setup.exe` and verify it against
`SHA256SUMS.txt`. The installer preserves the existing ledger and company credentials.

The release pipeline validates the version, formatting, types, lint, and tests before
building the installer and publishing the release. A failed stage prevents publication.
