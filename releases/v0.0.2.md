Cash Ledger adds company setup, local sign-in, reporting, and application updates.

- Renames the desktop app and installer to Cash Ledger while preserving existing cash records and installation identity.
- Adds first-run company setup with an administrator username and salted Argon2id password hashing.
- Adds Settings for company details, cash-handling rules, closing variance warnings, and Windows printer preferences.
- Adds date and register reports, CSV exports, and native Windows printing.
- Adds automatic update checks, verified installer downloads, and install-and-restart controls in Settings. Installation waits for unfinished work to be saved or cleared.

Download `CashLedger-0.0.2-windows-x64-setup.exe` and compare its hash against
`SHA256SUMS.txt`. Existing Till users must install this version manually once to
enable future automatic updates. Existing registers, cash records, and database
location are preserved. First launch requires company setup; later launches
require sign-in.

Windows 10 version 1703 or later and Windows 11 x64 are supported. The installer
is unsigned. Updates trust this GitHub repository and verify the GitHub-supplied
SHA-256 asset digest. Uninstall preserves the database.

Known limitations: one local administrator account, no email password recovery,
CAD-only registers, and no cloud synchronization. Native printing is available
only on Windows. An upstream accessibility integration issue can cause a panic
on native Windows shutdown with active accessibility clients. Installer creation
and automated checks are covered by CI; a live installed upgrade/relaunch cycle
has not yet been manually verified in a Windows VM.
