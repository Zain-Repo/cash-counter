# Cash Ledger 0.0.5

- Add a live dashboard with cash-flow charts, register rankings, closing discrepancies, and date-range controls.
- Run bounded analytics on a background read-only connection with consistent snapshots, query deadlines, and stale-result protection.
- Add verified online SQLite backups that include committed WAL records and preserve existing destinations.
- Stream CSV exports and filter report queries before loading movement details.
- Add a date-range index migration and an isolated performance example supporting one million movements.
- Guard sign-out and application restart while a backup is in progress.

## Known limitations

- Dashboard UI totals cover CAD registers; refreshes occur while the dashboard is active.
- Backup scheduling, encryption, and in-app restore are not implemented.
- Benchmark memory measurements cover the isolated example, not the desktop application.
- Native visual inspection of the new dashboard remains unverified; automated tests and static checks passed.
